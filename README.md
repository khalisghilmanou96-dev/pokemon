# Mini Pokédex

Site statique utilisant [PokéAPI](https://pokeapi.co/), prêt à être hébergé gratuitement avec GitHub Pages.

## Fonctionnalités

- Liste de Pokémon avec images, types et numéros
- Recherche par nom ou numéro
- Pokémon aléatoire
- Fiche détaillée dans une fenêtre modale
- Statistiques, taille, poids et expérience de base
- Interface responsive mobile / tablette / ordinateur

## Déploiement sur GitHub Pages

1. Crée un nouveau dépôt GitHub.
2. Ajoute `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Dans le dépôt, ouvre **Settings > Pages**.
4. Dans **Build and deployment**, sélectionne **Deploy from a branch**.
5. Choisis la branche `main` et le dossier `/ (root)`.
6. Clique sur **Save**.

GitHub affichera ensuite l'adresse publique du site.
